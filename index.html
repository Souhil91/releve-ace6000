      La sonde n'apparaît pas dans la liste ?
      • Sonde allumée, voyant Bluetooth actif, batterie chargée. Elle n'accepte qu'une connexion à la fois : déconnectez-la de tout autre téléphone ou PC.
      • Android, mode SPP : Réglages → Bluetooth → Associer un appareil → « xxxxxx.SPP » (pas de code PIN). Mettez Chrome à jour depuis le Play Store.
      • Android, mode BLE : n'associez pas le « .BLE » dans les réglages ; choisissez-le directement ici. Autorisez Chrome à utiliser « Appareils à proximité » (Réglages → Applications → Chrome → Autorisations) et activez la Localisation.
      • Windows : Paramètres → Bluetooth et appareils → Ajouter un appareil → « xxxxxx.SPP ». Fermez les autres logiciels qui utilisent la sonde (ACE Pilot, OP Manager…). Si deux ports COM sont créés, essayez l'autre.
      • iPhone : le mode SPP est impossible ; utilisez le navigateur Bluefy et le mode BLE.
