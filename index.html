      Outils de la sonde TESPRO (mode IEC automatique)

      En mode « IEC auto » (réglage d'usine), la sonde suit la négociation optique 300 → 9600 bauds. Si le compteur ne répond pas après la négociation, désactivez-le : la sonde reste alors à 9600 bauds fixe, ce qui convient au HDLC direct. Commandes documentées par TESPRO (firmware V4.50 ou plus), enregistrées dans la sonde.

        La sonde n'apparaît pas dans la liste ?
        • Sonde allumée, voyant Bluetooth actif, batterie chargée. Elle n'accepte qu'une connexion à la fois : déconnectez-la de tout autre téléphone ou PC.
        • Android, mode SPP : Réglages → Bluetooth → Associer un appareil → « xxxxxx.SPP » (pas de code PIN). Mettez Chrome à jour depuis le Play Store.
        • Android, mode BLE : n'associez pas le « .BLE » dans les réglages ; choisissez-le directement ici. Autorisez Chrome à utiliser « Appareils à proximité » (Réglages → Applications → Chrome → Autorisations) et activez la Localisation.
        • Windows : Paramètres → Bluetooth et appareils → Ajouter un appareil → « xxxxxx.SPP ». Fermez les autres logiciels qui utilisent la sonde (ACE Pilot, OP Manager…). Si deux ports COM sont créés, essayez l'autre.
        • iPhone : le mode SPP est impossible ; utilisez le navigateur Bluefy et le mode BLE.

          Paramètres avancés
          Liaison optique

          L'ACE6000 a été vu répondre en HDLC direct sur la tête optique. Le mode automatique essaie d'abord le HDLC direct, puis le mode E.

          DLMS / COSEM

          Mot de passe binaire : préfixez par hex: (ex. hex:3132333435363738). Valeurs usine Itron documentées : client 1, mot de passe ABCDEFGH — utilisez celles de votre service. Attention : la configuration ACE6000 bloque l'accès après 3 mots de passe erronés.

          En recherche automatique, l'appli essaie d'abord l'adresse logique 2 / physique 17 sur 4 octets (constatée sur un ACE6000), puis les autres adresses usuelles, et retient celle qui répond. Tête optique en mode manuel : adresse physique vide ou 17. Port client RS485/RS232 de la configuration ACE6000 : adresse physique 30.
